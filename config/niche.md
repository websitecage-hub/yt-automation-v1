## EDITING LAW
- The viewer NEVER goes 2.5 seconds without a visual reward.
- Every concept is SHOWN, then ANIMATED, then MEMED. Core loop:
  concept -> visual -> joke/reward -> next concept.
- Screen is always 3 layers: base art, beat overlays, avatar+meme. Never base alone.
- Avatar bottom-right, always visible, reacts at meme moments.

## FORMAT (every video = LESSON #NNN)
- HOOK (0:00-0:30): personal pain + betrayal + the big question. No intro. Ever.
- PROMISE (0:30-0:50): "By the end you'll know exactly how X works. Other videos
  teach this backwards. We start from the raw physics."
- STAIRCASE (0:50-6:30): 7-10 steps, each ONE sentence, each visualizable, each
  built from the previous step's output. The viewer feels progressively smarter.
- PAYOFF (6:30-7:30): existential zoom-out ("every heartbeat you've ever had is
  just...") + the VERDICT stamp: APEX / THREAT / SLEEPER / FRAUD.
- LOOP (last 15s): tease 3 future lessons by name. Comment bait.
- ~1,300 words (fast delivery ≈ 7:30-8:00), 1920x1080, 60fps.

## SCRIPT RULES
- Every claim = mechanism AND number. Never "studies show."
- Staircase steps must chain: step N+1 uses step N's output.
- Fast conversational sentences. First person. Pain stories allowed.
- Power-scaling language is the brand: base stats, hidden ability, power seal,
  final form, awakening, nerf, buff — 2-3 per video.
- Each catchphrase exactly once: "Let's check the base stats." /
  "Two hundred million years of field research." /
  "Class dismissed. Evolution isn't finished with you."
- Contested claims labeled contested. No medical advice.
